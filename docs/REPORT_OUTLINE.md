# 课程报告大纲（可直接扩写）

> 口径：本方案为 **training-free 外挂模块**，不涉及模型训练，故**无需训练集**；Persona-Chat 仅作**评测数据集**。  
> 基座：开题为 Qwen2.5-7B-Instruct；因账号未开通，实验使用 **qwen3.8-max**（方法不变，报告中需说明）。

---

## 1. 引言（约 0.5–1 页）

- **问题**：多轮角色对话中的人设漂移（性格矛盾、背景遗忘、风格跳变、接受错误设定）
- **难点**：纯靠 system prompt 难稳住长程与诱导探针
- **本文贡献**（三条对应展望落地）：
  1. 结构化人设档案 + 后置校验 + 有限重试
  2. L1 规则 + L2 语义（含隐晦冲突）分层校验
  3. RAG 人设记忆（嵌入检索 + 动态更新）与多角色协同 demo

## 2. 相关工作 / 课程知识点落点（约 0.5 页）

| 课件 | 项目落点 |
|---|---|
| Ch8 LLM-as-judge | 校验器与评测 judge |
| Ch8 提示工程 | 档案注入、修正型重试 prompt |
| Ch4 采样 | 生成 T=0.7，校验/judge T=0 |
| Ch6 生成评估 | BLEU 不适用，改用漂移率 + judge + 人工 |
| Ch5 长程依赖 | 长程探针与 G2+ 记忆 |

## 3. 方法（约 1.5–2 页）

### 3.1 总体架构
人设档案 → 生成器 → 校验器 →（冲突则重试 ≤2，临时消息 pop）→ 输出

### 3.2 结构化档案
5 字段：`name / personality / background / hobbies / speech_style` + 原始 sentences

### 3.3 分层校验（展望1）
- **L1**：关键词/正则硬冲突（可解释、零成本）
- **L2**：LLM 语义审计，含隐晦冲突 few-shot，T=0

### 3.4 RAG 记忆（展望2）
- `text-embedding-v3` 检索历史人设事实
- 每轮抽取事实写入记忆库；可选 consolidate 抑制漂移记忆

### 3.5 多角色协同（展望3）
每角色独立档案 + 校验 + 记忆，共享对话上下文（case study，不进主指标）

## 4. 实验设置（约 1 页）

- **评测集**：Persona-Chat valid，20 角色 × 10 探针 = 200 条
- **探针类型**：自我介绍 / 细节 / 抗诱导 / 风格诱导 / 虚假记忆 / 设定越界 / 长程回指
- **对照**：

| 组 | 配置 |
|---|---|
| G0 | 平铺人设，无档案无校验 |
| G1 | 结构化档案 |
| G2 | 档案 + 校验 + 重试 |
| G2+ | G2 + RAG 记忆 |

- **指标**：漂移率、一致性、流畅度、重试率、修正成功率；人工抽检一致率（附录）

## 5. 结果与分析（约 1.5–2 页）——填真数

| 指标 | G0 | G1 | G2 | G2+ |
|---|---|---|---|---|
| 漂移率↓ | 9.5% | 10.5% | 0.5% | **0.0%** |
| 一致性↑ | 4.40 | 3.95 | 4.40 | **4.50** |
| 流畅度 | 4.95 | 4.80 | 4.95 | 4.85 |
| 重试率 | — | — | 8.0% | 6.5% |
| 修正成功率 | — | — | 93.8% | **100%** |

**叙述逻辑（照抄可改）：**
1. G0 复现漂移；风格诱导漂移最高（35%），对应 PPT 局限2  
2. G1≈G0：说明**只堆档案不够**  
3. G2 漂移降至 0.5%，修正成功率 93.8%：**校验是主贡献**  
4. G2+ 到 0%，长程/诱导类冲突被进一步压住  
5. 流畅度四组持平 → 外挂模块**基本不影响自然度**

## 6. 案例与局限（约 0.5–1 页）

- **正例**：虚假记忆探针下 G0 接受错误前提，G2/G2+ 拒绝并纠偏  
- **局限**：
  1. LLM-as-judge 有偏好风险 → 人工抽检一致率  
  2. 记忆库可能积累早期漂移（报告写出即加分）  
  3. 多角色仅 case study，未大规模量化  
  4. 基座由 7B 改为 qwen3.8-max，绝对数值不可与 7B 直接横向比

## 7. 结论与展望（约 0.3 页）

- 结论：training-free 外挂可显著降低人设漂移，校验模块贡献最大  
- 展望（已部分完成，可写“后续可…”）：更细粒度规则库、记忆矛盾检测、多角色大规模评测

## 答辩三问速记

**Q：校验误判怎么办？**  
A：T=0；重试上限 2；人工抽检一致率 XX%。

**Q：为什么不微调？**  
A：算力、标注、6 周周期；外挂零训练、角色即插即用。

**Q：漂移率怎么定义？**  
A：冲突条数/总条数；prompt 附附录；与人工一致率 XX%。
